## 安装步骤

1. 从上述网站下载 TTF 格式字体文件
2. 将字体文件复制到 `PDF_HandWrite/TTF/` 文件夹
3. 重启手写模拟器程序
4. 在字体下拉菜单中选择新字体

## 使用建议

1. **字体大小**：推荐 18-24pt，根据PDF页面大小调整
2. **字符抖动**：设置 0.5-2.0 的轻微抖动增加真实感
3. **行倾斜**：设置 1-3 度的轻微倾斜模拟自然书写
4. **颜色**：使用深灰色 (#333333) 比纯黑色更自然

## 注意事项

- 确保字体文件为 `.ttf` 格式
- 字体名称不要包含特殊字符
- 中文字体文件较大，加载可能需要几秒钟
- 如果字体显示异常，尝试重启程序

## 优化效果技巧

1. **混合使用**：中英文使用不同手写字体
2. **随机性**：适当增加大小和位置抖动
3. **行间距**：设置为字体大小的 1.2-1.5 倍
4. **字间距**：设置为字体大小的 0.1-0.2 倍

通过合适的字体选择和参数调整，可以生成非常接近真实手写的PDF文档。

## Installation Steps

1. Download TTF format font files from the websites mentioned above
2. Copy the font files to the `PDF_HandWrite/TTF/` folder
3. Restart the handwriting simulator program
4. Select the new font from the font dropdown menu

## Usage Suggestions

1. **Font Size**: Recommended 18-24pt, adjust according to PDF page size
2. **Character Jitter**: Set 0.5-2.0 for subtle jitter to increase realism
3. **Line Tilt**: Set 1-3 degrees for slight tilt to simulate natural writing
4. **Color**: Use dark gray (#333333) for more natural appearance than pure black

## Important Notes

- Ensure font files are in `.ttf` format
- Font names should not contain special characters
- Chinese font files are larger and may take a few seconds to load
- If font display is abnormal, try restarting the program

## Optimization Tips

1. **Mix Fonts**: Use different handwriting fonts for Chinese and English
2. **Randomness**: Appropriately increase size and position jitter
3. **Line Spacing**: Set to 1.2-1.5 times the font size
4. **Character Spacing**: Set to 0.1-0.2 times the font size

With proper font selection and parameter adjustments, you can generate PDF documents that closely resemble real handwriting.
